# # Smart Text Analyzer Using Keyword Frequency Counter

## Introduction
Smart Text Analyzer is a Python mini project that counts word frequency in a text using a Dictionary (Hash Table).

## Objectives
- Count the frequency of each word.
- Search for a specific keyword.
- Display the top 5 frequent words.
- Show total and unique words.

## Technologies Used
- Python
- Dictionary (Hash Table)
- VS Code

## Features
1. Enter text.
2. Display word frequency.
3. Search keywords.
4. Display top 5 words.
5. Show text statistics.

## Conclusion
This project demonstrates how Hash Tables help store and search word frequencies efficiently.
